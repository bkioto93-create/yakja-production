# بازطراحی صفحه‌ی اصلی یکجا — راهنمای نصب

## خلاصه‌ی کارهایی که انجام شد
طبق درخواستت، صفحه‌ی اول این‌ها را الان دارد:

1. **بنر اسپلیت بهتر** — نشان کوچک «پلتفرم محلی افغانستان»، تیتر و زیرتیتر تازه (شعار قبلی
   عوض شد)، و سه برچسب اعتماد («چهار خدمت در یک اپ»، «مستقیم و بدون واسطه»، «دری و پشتو»).
2. **چهار بنر پیش‌رونده‌ی افقی** — رانندگان تازه (عکس+نام+وسیله)، متخصصین تازه (عکس+نام+تخصص)،
   آگهی‌های تازه‌ی کالا، آگهی‌های تازه‌ی ملک. هرکدام لینک «دیدن همه» هم دارند.
3. **بخش «چرا یکجا؟»** — شش ویژگی واقعی (چهار خدمت یک‌جا، تماس مستقیم، بررسی‌شده، دوزبانه،
   رایگان، امکان گزارش تخلف).
4. **بخش پرسش‌های پرتکرار** — شش سوال/جواب رایج، به‌صورت آکاردئون قابل باز/بسته‌شدن.
5. **فوتر کاملاً بازطراحی‌شده** — درباره‌ی ما، دسترسی سریع، شماره‌ی پشتیبانی (قابل تماس مستقیم
   با لمس)، و بخش دانلود اپلیکیشن (آیکون یکجا + آیکون اندروید، فعلاً «به‌زودی»).
6. **کش برای اینترنت ضعیف** — چهار کوئری «جدیدترین‌ها» هرکدام ۳ دقیقه کش می‌شوند؛ یعنی حتی با
   بازدید زیاد هم‌زمان، دیتابیس فشار زیادی نمی‌بیند و صفحه سریع لود می‌شود.

## نحوه‌ی نصب (کپی مستقیم روی پروژه)
ساختار پوشه‌ی داخل این پکیج دقیقاً همان مسیر پروژه‌ی توست. کافیست محتوای پوشه‌ی `src` را
داخل `C:\projects\yakja\src` کپی کنی و اجازه بده فایل‌های هم‌نام Overwrite شوند.

| فایل | نوع | توضیح |
|---|---|---|
| `src/app/[lang]/page.tsx` | ویرایش | صفحه‌ی اصلی، بازطراحی کامل |
| `src/app/[lang]/HomeShowcaseBanners.tsx` | جدید | چهار بنر افقی رانندگان/متخصصین/کالا/ملک |
| `src/app/[lang]/HomeFeatures.tsx` | جدید | بخش «چرا یکجا؟» |
| `src/app/[lang]/HomeFaq.tsx` | جدید | بخش پرسش‌های پرتکرار |
| `src/components/layout/Footer.tsx` | ویرایش | فوتر جدید |
| `src/components/ui/Icons.tsx` | ویرایش | افزودن آیکون‌های Menu (قبلی)، ChevronDown، Android |
| `src/lib/home/homeQueries.ts` | جدید | کوئری‌های کش‌شده‌ی «جدیدترین‌ها» |
| `src/lib/config/appLinks.ts` | جدید | محل تنظیم لینک دانلود اندروید (بعداً) |
| `src/dictionaries/fa.ts` | ویرایش | متن‌های جدید فارسی |
| `src/dictionaries/ps.ts` | ویرایش | متن‌های جدید پشتو |

## ⚠️ یک قدم اضافه (خیلی مهم، ولی ساده) — اجرای اسکریپت SQL
فایل `SUPABASE_MIGRATION_service_providers_created_at.sql` را باز کن؛ داخلش توضیح کامل و
مرحله‌به‌مرحله هست، ولی خلاصه‌اش:

1. وارد پنل Supabase پروژه‌ات شو.
2. از منو روی **SQL Editor** بزن → **New query**.
3. محتوای فایل SQL را کپی/پیست کن و **Run** بزن.

چرا لازم است؟ جدول متخصصین (`service_providers`) از قبل تاریخ ثبت نداشت، پس بدون این اسکریپت،
ردیف «متخصصین تازه» ممکن است متخصصین کاملاً قدیمی را هم به‌صورت تصادفی نشان بدهد. بعد از اجرای
اسکریپت، طبق راهنمای داخل فایل `src/lib/home/homeQueries.ts` (دقیقاً مشخص‌شده با علامت 🔶)، یک
خط را عوض کن. اگر این قدم را فراموش کنی، سایت خراب نمی‌شود، فقط ترتیب «تازگی» متخصصین دقیق
نخواهد بود.

## نکته درباره‌ی دکمه‌ی دانلود اپلیکیشن
فایل `src/lib/config/appLinks.ts` را باز کن؛ یک متغیر خالی (`ANDROID_APP_DOWNLOAD_URL`) آنجاست.
وقتی اپلیکیشن اندروید آماده شد، فقط آدرس گوگل‌پلی (یا هر لینک مستقیم دیگر) را داخل آن کوتیشن‌ها
بگذار؛ دکمه‌ی فوتر خودکار از حالت «به‌زودی» به حالت فعال و قابل‌کلیک تغییر می‌کند — هیچ فایل
دیگری نیاز به تغییر ندارد.

## تست بعد از نصب
```powershell
npm run dev
```
سپس این‌ها را چک کن:
- `/fa` و `/ps` (صفحه‌ی اصلی هر دو زبان)
- اگر هنوز هیچ راننده/متخصص/آگهی/ملکی ثبت نشده، هر بنر باید پیام «هنوز ثبت نشده» را نشان بدهد
  (نه خالی/خراب)
- روی گوشی (یا حالت موبایل DevTools) بنرها باید با انگشت به‌راحتی اسکرول افقی شوند
- بخش «پرسش‌های پرتکرار» باید با لمس هر سوال باز/بسته شود

اگر هر خطایی گرفتی، متنش را برایم بفرست تا سریع رفع کنم.
